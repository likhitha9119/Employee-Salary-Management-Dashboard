# Employee Salary Management Dashboard

## Project Overview
This project is an Employee Salary Management Dashboard created using Microsoft Excel.

## Features
- Employee salary records
- Gross Salary and Net Salary calculation
- Total Deductions
- Highest Net Salary
- Lowest Net Salary
- Average Net Salary
- Interactive Dashboard with Charts

## Tools Used
- Microsoft Excel
- Formulas (SUM, AVERAGE, MAX, MIN)
- Charts
- Conditional Formatting

- Employee_Salary_Management_Dashboard.xlsx
